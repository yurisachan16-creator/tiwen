# 30题编辑校准草案

本文件由 `content/questions.json` 生成，该 JSON 是评议记录的单一来源。保留原题编号；原题见 [候选问题](QUESTIONS.md)。

这是一轮编辑建议，不代表维护者已审定，也没有真实受众数据。目标是减少作业感，而不是把所有问题改成轻松闲聊。需要按 [评测规范](EVALUATION.md) 完成人工盲评。

结果：保留 8 题，改写 19 题，暂时淘汰 3 题。“保留”指保留切入点与主任务，仍可补充独立阅读所需的假设措辞。淘汰项仍保留用于追溯，不进入预览候选池。

| A02 | 改写 | 原题连续要求改造与影响评估，收成一个有趣的使用摩擦。 | 有没有一件东西，你已经熟练掌握了它“不好用”的那一部分？它让你学会了什么奇怪的小动作？ |

| A04 | 改写 | 给出更可见的矛盾，不先要求换位分析。 | 一扇写着“推”、却总让人想拉的门，可能是哪里在误导人？ |
