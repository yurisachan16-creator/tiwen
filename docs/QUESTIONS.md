# 候选问题与改写

**状态：待评议的编辑样例。** 以下 30 题各类 15 题，用于讨论、质量评议与预览测试，不是通过审核的发布队列。未来上线时仍须重新检查事实前提、重复情况和平台长度。

判断标准见 [PRD](PRD.md)。回答者可以使用公共情境或虚构例子，不必透露个人信息。

## A. 日常观察：15 题

| 编号 | 候选问题 | 练习重点 |
| --- | --- | --- |
| A01 | 找一处你经常经过的公共空间：哪一个不起眼的细节，改变了人们走路或停留的方式？ | 从细节观察行为 |
| A02 | 选一件你经常使用、却总要迁就它的东西。你会改哪里？谁使用时可能反而不方便？ | 设计与影响 |
| A03 | 回想一件让你意外的小事。除了最先想到的原因，还有什么能解释它？哪条线索能帮你分辨？ | 替代解释与证据 |
| A04 | 看看附近的一块指示牌。一个第一次来这里的人，可能会怎样理解它？ | 换位与信息设计 |
| A05 | 找一个你熟悉的排队场景。除了队伍长短，还有什么能帮助你判断要等多久？ | 多变量观察 |
| A06 | 选一个你最近觉得顺手的工具。它替你省掉了哪一步？那一步原来有什么作用？ | 理解流程变化 |
| A07 | 找一张你觉得有用的清单。假如只能留下三项，你会用什么标准选择？ | 约束下排序 |
| A08 | 找一个你习惯说的词，比如“方便”或“划算”。什么例子能说明它对不同人意味着不同东西？ | 概念与语境 |
| A09 | 观察一件普通物品的包装。除了装住物品，它还在帮助人做什么？ | 发现隐含功能 |
| A10 | 想一段容易被误解的日常说明。只改一句话，你会怎样让第一次看到的人更容易行动？ | 清晰表达 |
| A11 | 选一个你熟悉的工作流程。假如其中一步暂时不能做，哪些步骤仍然可以继续？ | 依赖关系 |
| A12 | 找一个你见过的“默认选项”。如果它换了，人们的行为可能怎样变化？ | 默认与行为 |
| A13 | 回想一个你改变了理解的时刻。哪个具体细节，让原来的解释不再够用了？也可以举公开事件的例子。 | 更新理解 |
| A14 | 选一件看起来“很费时间”的小事。怎样观察，才能知道时间究竟花在了哪里？ | 拆解与测量 |
| A15 | 找一个人们自发形成的小规则，比如留座或借东西。它解决了什么问题，又在哪种情况下容易失灵？ | 规则与边界 |

## B. 跨领域挑战：15 题

以下均为明确的假设场景，不能把场景中的现象转述成现实研究结论。

| 编号 | 候选问题 | 练习重点 |
| --- | --- | --- |
| B01 | 一座公园只能做一项改造：你会先观察什么，再决定把钱花在哪里？ | 需求与取样 |
| B02 | 一家书店把书按“读完后的感受”分类。你会怎样让第一次来的读者找到想读的书？ | 分类与检索 |
| B03 | 假设同一杯水，有人觉得温、有人觉得凉。你会怎样设计一个小实验，区分可能的原因？ | 实验设计 |
| B04 | 两家店都说顾客满意度是 90%。在比较之前，你最想知道这个数字是怎样得到的？ | 测量与样本 |
| B05 | 一款学习工具让完成练习的人数增加了。还需要观察什么，才能判断大家是否学会了？ | 指标与目标 |
| B06 | 假设城市停电一小时。你会根据什么，判断哪些看似互不相关的服务会一起受影响？ | 系统依赖 |
| B07 | 给第一次见到自行车的人写一句说明，帮助他理解它怎样保持前进。你会从哪个现象开始讲？ | 建立解释 |
| B08 | 假设一项比赛允许参赛者自己选评分标准。你会怎样设计规则，让不同作品仍能被有意义地比较？ | 公平与评价 |
| B09 | 一座博物馆要介绍一个已经消失的职业，只能展出三件物品。你会怎样选择，才能让人理解它的日常？ | 信息选择与叙事 |
| B10 | 一张地图把距离画得不准确，却仍然很好用。它可能保留了哪些信息？ | 抽象与用途 |
| B11 | 假设推荐系统总能找到你喜欢的内容。你会怎样设计一个小功能，让你也有机会遇见尚不知道自己会喜欢的东西？ | 探索与设计 |
| B12 | 一个小岛想统计鸟的数量，却只能每天观察十分钟。你会怎样安排观察，让估计更可信？ | 取样与不确定性 |
| B13 | 一个共享工具箱总有工具迟迟没被归还。怎样先了解原因，再决定是否增加惩罚？ | 行为解释与干预 |
| B14 | 假设你要向没见过海的人解释“潮汐”。你会选什么熟悉的事物作比喻？这个比喻会在哪一点失效？ | 类比与边界 |
| B15 | 一家餐厅减少了菜单选项，点餐速度变快了。除了选择变少，还有哪些变化可能解释这个结果？ | 因果与混杂 |

## 差题分析与改写：8 组

改写展示思路，不构成额外的已审核题库；其中一些与上表重合，不能重复发布。

| 差题 | 问题所在 | 改写 |
| --- | --- | --- |
| 如果 AI 比你做得好，你还会继续练习吗？ | 先假设一个笼统的“更好”，再逼选继续或放弃，容易引向热爱的口号 | 选一项你熟悉的技能：其中哪些细节，只有亲自做过才容易留意？你会用什么例子向初学者说明？ |
| 效率和公平哪个更重要？ | 抽象二选一，没有具体约束，也没有说明谁受影响 | 想象一家诊所有预约者和临时来访者。你会怎样安排等候顺序？哪些情况需要例外？ |
| 为什么现代人越来越没有耐心？ | 将未经证实的趋势当成前提，诱导用户解释它 | 比较两种你见过的等待场景：哪些细节会让同样长的等待感觉不同？ |
| AI 必然让人变懒，我们应该怎么办？ | 结论先行，忽略任务、用法和个体差异 | 同一项任务，怎样使用 AI 会让人多想一步？怎样的用法可能省掉那一步？请选一个具体任务说明。 |
| 人生的意义是什么？ | 题目过宽，短时参与没有抓手，容易回到熟悉口号 | 选一项人们愿意反复做、却没有外部奖励的活动。哪些细节能帮助你理解它的吸引力？ |
| 请说出你最痛苦的秘密，它如何塑造你？ | 要求公开敏感经历，把自我披露当参与条件 | 故事里的一个人物改变了选择。作者可以用什么细节，让读者理解这个变化而不直接解释？ |
| 相关性不等于因果性，对吧？ | 只邀请附和，知道口号不等于会运用 | 一家餐厅减少菜单后点餐变快了。你会检查哪些同时发生的变化，再判断原因？ |
| 你为什么认同自己的回答？为什么？再为什么？ | 脱离具体回答，机械延长对话，把追问当作质量 | 针对用户实际提出的依据，选择一个尚未解释的细节追问；若理由已充分，补充一个适用边界或结束。 |

## 怎样评议这些样例

先独立写一个可能的回答，再尝试另一条不同的回答路径。标记需要额外知识、暗含立场、可能触及隐私以及与其他题目相似的地方。给出具体改写，不只判断“深刻”或“无聊”。

若题目只有在阅读“练习重点”后才知道如何回答，应改写题干。选题时不把这些说明附到每条帖子里替用户规定思路。
